Dump from the flight controller

Reads every parameter from the flight controller and stores it on the boat as a .param file, in the same NAME,VALUE format Mission Planner and QGroundControl use. Read-only — nothing is written to the FC.

Load from a file on this device
This writes to the flight controller. Loading the wrong file can make the boat unflyable. Dump the current parameters first so you have a way back, and keep the FC disarmed. This writes to the flight controller only — it does not change the backup stored on the boat.

Auto-tune

Measure the boat and set the steering and speed controller gains.

FC

Works the same way ArduPilot’s rover-quicktune applet does — it measures how much steering output produces how much turn, and how much throttle produces how much speed, then sets the gains from those two ratios. That applet cannot run on this boat (the H743 has no SD card, so Lua is unavailable), so the boat does the same arithmetic itself.

You drive, the boat only watches. It never takes control and your sticks stay live throughout. Nothing is written to the flight controller until you press Apply on the result — and you will see every old and new value first.
What to do

1. Arm and get on open water. 2. Hold a steady turn — one full circle, about 10 s. 3. Then drive straight at a comfortable cruise for another 10 s. The console tells you if it needs more steering, more turn, more throttle or more speed.
